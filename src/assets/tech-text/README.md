# Demo fonts

Unmodified variable TrueType fonts from the Google Fonts repository:

- Geist.ttf: https://github.com/google/fonts/blob/main/ofl/geist/Geist%5Bwght%5D.ttf
- GeistMono.ttf: https://github.com/google/fonts/blob/main/ofl/geistmono/GeistMono%5Bwght%5D.ttf

Each font is licensed under the SIL Open Font License 1.1; the corresponding
Geist-OFL.txt and GeistMono-OFL.txt files are retained beside the font files.
These are local demonstration assets, not part of the reusable Tech Text ZIP.
The reusable component inherits any font already loaded in the consuming app.
